# Шпаргалка по Git

## Работа с папками

- `pwd` — показать путь к текущей папке
- `ls` — показать содержимое папки
- `cd имя-папки` — перейти в папку
- `cd ..` — перейти в родительскую папку
- `mkdir имя-папки` — создать папку

## Работа с Git

- `git init` — создать репозиторий в текущей папке
- `git status` — посмотреть состояние файлов
- `git add README.md` — подготовить изменения конкретного файла
- `git add .` — подготовить изменения текущей папки и её подпапок
- `git add --all` — подготовить все изменения в репозитории
- `git commit -m "Описание"` — создать коммит из подготовленных изменений
- `git log --oneline` — посмотреть краткую историю коммитов
- `git push` — отправить локальные коммиты на GitHub

## Понятия

Репозиторий — проект, историю изменений которого отслеживает Git.

Коммит — сохранённый снимок состояния проекта.

Git — система контроля версий.

GitHub — сервис для размещения репозиториев и совместной работы.
